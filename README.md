# Напоминалка — Telegram-бот напоминаний

Бот для небольшой группы пользователей (до ~20 человек) на **aiogram 3.x + SQLite (aiosqlite)**.
Понимает естественные формулировки дат на русском (через `dateparser`), крутится бесплатно
на облачном хостинге.

## Возможности

- **Разовые напоминания** естественным языком:
  `напомни завтра в 18:00 забрать посылку`, `через 2 часа позвонить маме`,
  `в пятницу в 09:30 встреча`, `15.11 в 09:30 оплатить счёт`,
  а также `забрать посылку завтра в 18:00` (дата в конце).
- В назначенное время бот присылает сообщение с кнопками **«Готово ✔»**, **«Отложить на 10 минут»**, **«Отложить на 1 час»**.
- **Повторяющиеся напоминания**: команда `/recurring` запускает мастер из 3 шагов
  (текст → дни недели кнопками → время кнопками или текстом `08:00`).
- **Управление**: `/list` (список активных + кнопка удаления каждого), `/cancel` (отмена шага), `/start` (приветствие).
- **Таймзона на пользователя**: определяется автоматически при первом сообщении (tzlocal, т.е. таймзона сервера) и правится командой `/timezone` (кнопки с городами или IANA-имя зоны).
- Проверка и отправка — фоновая задача, каждые **30 секунд**.
- Каждый пользователь видит только свои напоминания.

## Структура проекта

```
reminder-bot/
├── bot.py           # точка входа: polling + фоновый планировщик + HTTP /health (keep-alive)
├── handlers.py      # команды, мастер /recurring, парсинг естественного языка
├── scheduler.py     # фоновая отправка напоминаний (цикл 30 сек)
├── db.py            # SQLite через aiosqlite (users, reminders)
├── requirements.txt
├── render.yaml      # конфиг бесплатного деплоя на Render
└── README.md
```

## Шаг 1. Создание бота через @BotFather

1. Открой Telegram, найди **@BotFather**.
2. Отправь `/newbot`.
3. Придумай отображаемое имя (например `Напоминалка`).
4. Придумай username бота — должен заканчиваться на `bot` (например `my_reminder_ivan_bot`).
5. BotFather пришлёт **токен** вида `123456789:AAF...xyz` — сохрани его, никому не показывай.

> Если бота будут добавлять в группу: у BotFather команда `/setprivacy` → выбери бота → **Disable**
> (иначе бот не увидит обычные сообщения в группе).

## Шаг 2. Локальный запуск для теста

Нужен **Python 3.11+**.

```bash
cd reminder-bot

# виртуальное окружение
python -m venv .venv

# активация окружения
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Windows (cmd):
# .venv\Scripts\activate.bat
# Linux/macOS:
# source .venv/bin/activate

# зависимости
pip install -r requirements.txt

# токен в переменную окружения и запуск одной командой
# Linux/macOS:
TELEGRAM_BOT_TOKEN="123456789:AAF...xyz" python bot.py
# Windows PowerShell:
$env:TELEGRAM_BOT_TOKEN="123456789:AAF...xyz"; python bot.py
# Windows cmd:
# set TELEGRAM_BOT_TOKEN=123456789:AAF...xyz && python bot.py
```

В логе появится «Бот запущен, жду сообщения…» — открой чат с ботом, нажми `/start` и напиши,
например: `напомни через 1 минуту проверить бота`. Через минуту придёт напоминание с кнопками.
База создастся автоматически в файле `reminders.db` рядом с `bot.py`.

## Шаг 3. Бесплатный деплой на Render (рекомендуется)

1. Залей проект на **GitHub** (создай репозиторий, `git add . && git commit && git push`).
   Файл `render.yaml` уже в проекте — Render подхватит его автоматически.
2. Зайди на [render.com](https://render.com), войди через GitHub: **New → Web Service** → выбери репозиторий.
3. Render сам прочитает `render.yaml`:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
   - Plan: **Free**
4. В разделе **Environment** добавь переменную:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: твой токен из BotFather
5. Нажми **Deploy**. Через пару минут бот работает — логи смотри на вкладке **Logs**.

### Keep-alive (чтобы бот не засыпал)

Бесплатные Web Service на Render засыпают после ~15 минут без входящих запросов.
Бот поднимает endpoint `/health` специально для этого. Подними бесплатный внешний монитор:

1. Зарегистрируйся на [uptimerobot.com](https://uptimerobot.com) (или cron-job.org).
2. **Add New Monitor**:
   - Type: HTTP(s)
   - URL: `https://<имя-твоего-сервиса>.onrender.com/health`
   - Interval: **5 минут**
3. Готово: монитор пингует сервис, Render считает его «живым» и не усыпляет.

> Реальная работа бота идёт через long polling, входящие HTTP-запросы не нужны —
> `/health` существует только против засыпания.

### Альтернатива: Fly.io

```bash
fly launch --name reminder-bot --region waw
fly secrets set TELEGRAM_BOT_TOKEN="123456789:AAF...xyz"
fly deploy
```
У Fly.io бесплатные лимиты у новых аккаунтов сильно урезаны — Render проще и надёжнее для бота.

## Примечания

- **Автоопределение таймзоны** (`tzlocal`) на хостинге вернёт таймзону *сервера*, а не пользователя
  (Telegram не передаёт таймзону клиента). Поэтому после деплоя каждый пользователь должен
  один раз выполнить `/timezone` и выбрать свой город.
- Перезапуск бота не теряет напоминания — всё хранится в SQLite. Черновик мастера `/recurring`
  (шаги до сохранения) перезапуск не переживёт — начни мастер заново.
- Кнопка «Готово ✔» просто закрывает напоминание; «Отложить» переносит его (10 мин / 1 час),
  повторяющееся напоминание после откладывания продолжит работать по расписанию.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и инструкция |
| `/recurring` | Мастер повторяющегося напоминания |
| `/list` | Активные напоминания + удаление |
| `/timezone` | Смена часового пояса |
| `/cancel` | Отмена текущего шага |
